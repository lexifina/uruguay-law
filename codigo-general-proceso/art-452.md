# Artículo 452
Ejecución colectiva.-
Procede la ejecución colectiva cuando el deudor se encontrare en estado de cesación de pagos la que se realizará mediante el concurso para el deudor civil y la quiebra para el deudor comerciante.
La quiebra se regirá por las disposiciones pertinentes del Código de Comercio.
