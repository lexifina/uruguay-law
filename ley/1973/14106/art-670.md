# Artículo 670
Destínanse, por una sola vez, las siguientes partidas:
$ 350:000.000 (trescientos cincuenta millones de pesos) para la adquisición de cinco embarcaciones para patrullas en vías fluviales a $ 70:000.000 (setenta millones de pesos) cada una;
$ 400:000.000 (cuatrocientos millones de pesos) para la adquisición de dos embarcaciones para salvamento en alta mar a $ 200:000.000 (doscientos millones de pesos) cada una;
$ 100:000.000 (cien millones de pesos) para equipos de comunicaciones;
$ 150:000.000 (ciento cincuenta millones de pesos) para equipos de transporte.
