# Artículo 3

El destino de las carnes y subproductos comestibles de las reses no porcinas para otros fines que no sean la elaboración de embutidos, productos envasados, conservas o exportación, será penada con multas de cien a mil pesos.
En caso de reincidencia, el Poder Ejecutivo podrá retirar temporal, o
definitivamente, la autorización de faena acordada por la Dirección de
Ganadería.(*)
